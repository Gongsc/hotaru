Hotaru 托盘菜单 · 重设计预览

目标:两端均使用操作系统原生菜单(macOS = NSMenu 毛玻璃,Windows = Win32 上下文菜单随系统深浅色), 结构统一为「状态区 → 监控对象单选 → 操作区」三段,层级由两级降为零级。
本文件为纯设计预览,不代表实现。约束:muda 菜单项仅支持纯文本 / 勾选 / 禁用 / 分隔线 / 子菜单,不支持图标与彩色文字。
